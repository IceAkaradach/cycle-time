💡 คู่มือวิธีคุมคีย์บอร์ดตอนวิดีโอเปิด:

  • ⌨️ Spacebar : เริ่มต้นจับเวลา / สิ้นสุดรอบและบันทึกผล
  • ⌨️ แป้นตัว P : หยุดเล่นวิดีโอชั่วคราว / เล่นวิดีโอต่อ
  • ⌨️ แป้นตัว R : ย้อนกลับไปจุดเริ่มต้นวิดีโอ (00:00)
  • ⌨️ แป้นตัว Q : กดสิ้นสุดการทำวิดีโอและเข้าสู่หน้าดาวน์โหลดไฟล์ Excel
  • ⚡ แป้น [ หรือ - : ลดความเร็ววิดีโอ | แป้น ] หรือ + : เพิ่มความเร็ววิดีโอ (ปรับได้ถึง 5.0x)
  • ⏩ ลูกศร ซ้าย / ขวา (← / →) : ก้าวทีละเฟรม (0.05s) | Shift + (← / →) : ก้าวทีละ 1 วินาที
  • 🎯 โหมดรอบแม่แบบ (Template Master) : บันทึกขั้นตอนรอบแรกด้วยมือ จากนั้นกดล็อคแม่แบบเพื่อให้ระบบจับเวลาและเปลี่ยนขั้นตอนรอบต่อไปอัตโนมัติ
